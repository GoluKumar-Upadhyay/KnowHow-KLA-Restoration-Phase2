# Acknowledgements

## Dataset

This work uses a **derived dataset** based on the **NFFA-EUROPE - 100% SEM
Dataset** (Version 2.0), a collection of 21,169 Scanning Electron Microscopy
(SEM) images classified into 10 categories, produced at CNR-IOM (Trieste,
Italy).

### Modifications Made to the Original Dataset

The original SEM images were not used directly. The following transformations
were applied to create the derived dataset used in this work:

- Multiple patches were extracted from various images in the original dataset.
- Synthetic noise was added to the extracted patches.

The derived dataset therefore differs from the original and the original authors
bear no responsibility for the modifications or any conclusions drawn from the
modified data.
